- `roon_cover` works with the internal protocol on. With `DEEP_ROON_INTERNAL=on` it took the cover key from Roon's internal graph but asked for it on the official `/api/image/` endpoint, which only knows the official API's keys — so it always answered "Roon doesn't hand over the cover right now". It now uses the zone's official image key first and falls back to the internal key on the path the Core serves it. Thanks to Dirk-Pitt for the careful report on the Roon forum.
