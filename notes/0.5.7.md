- **Edit your own playlists** (experimental, off by default) — four new tools add, remove, move and rename tracks in an existing Roon playlist, instead of making a new one for every change. Switch them on with **Edit existing playlists** in Claude Desktop's settings, or `DEEP_ROON_PLAYLIST_EDIT=1`. Only your own Roon playlists; imported, smart, Qobuz and TIDAL playlists are refused, and with a read-only library the tools aren't there. Each edit starts from a fresh snapshot, is checked again right before it's written and read back in full afterwards; if the result doesn't match, Deep Roon says so and never tries again by itself. A track that's in a playlist twice is handled per copy. Contributed by kvarnelis on GitHub — with tests, docs and a careful round on a live Core. Thank you!
- `roon_playlist_snapshot` — one of your playlists complete, with an id for every track in it. Always there; it only reads.
- Renaming onto a name another playlist already has is refused up front, with a plain message.
