For library maintenance: what Roon identified, how it grouped discs, and what's in your files.

- **`roon_library` takes `identified`.** It's the same filter as Identified / Unidentified in Roon's Focus. `identified: false` lists the albums Roon couldn't identify.
- **`roon_album` says whether Roon identified the album** (`identified`). It also gives Roon's own id for the metadata album it matched (`roon_album_id`) and, when that match is AllMusic's, the AllMusic id (`allmusic_id`, the one in AllMusic's URLs). A MusicBrainz id isn't in what Roon's protocol returns.
- **`roon_album` gives the number of `discs`**, also when there is one. The disc number per track was already there for albums with more than one disc. Together they show whether Roon took a folder as one multi-disc album or as several albums.
- **`roon_album` takes `file_tags: true`.** It adds the tags as they are in each local file, per track, `ROONALBUMTAG` and `ROONTRACKTAG` included. Streaming albums have no files, so they have no file tags.
