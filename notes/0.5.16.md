- **Storage by name.** `roon_library` and `roon_focus` take any storage location by the name Roon shows for it (Settings › Storage): `storage: "Hi-Res"`, `"DSD"`, `"Classical"`. `"local"` now means every local folder — it used to pick only the first one, so on a Core with several watched folders part of the library went missing. `"tidal"` and `"qobuz"` work as before, and an unknown name lists the ones that exist. Focus names each local folder the way Roon does, instead of "Local" for all of them. Contributed by guyp2k on GitHub.
- **`roon_status` says when you're up to date.** It only mentioned a newer version when there was one, so no news looked like no answer. Now `update` says "up to date", names the newer version with its link, or says it couldn't check.
